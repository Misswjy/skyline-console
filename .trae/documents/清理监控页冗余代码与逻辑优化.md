## 目标

- 移除不必要的依赖与冗余函数，减少请求与复杂度，提升稳定性。

## 变更项

1. 删除 index.jsx 未使用的 `bizcharts` 组件导入（Chart/Interval/Tooltip/Axis/Coordinate）。
2. 移除 CPU 图表中的随机模拟数据回退逻辑，空数据时返回空集合即可。
3. 移除已冗余的 `fetchCreatedMsFromExtension` 调用与函数，统一改用 `fetchDomainAndCreatedFromExtension` 获取 `domain` 与 `createdMs`，避免重复请求。

## 验证

- 构建与运行不报错，监控页加载稳定。
- CPU 图空数据时不显示曲线但无异常；域名与创建时间只通过扩展 API 或回退一次 Prom 查询获取。
